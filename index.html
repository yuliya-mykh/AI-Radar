    Про проєкт

    AI Radar — невеликий каталог AI-сайтів на даних публічного API freeserp.ai (index=sites, ніша AI).

    Мета

    Допомогти швидко знайти AI-сервіс під конкретне завдання, оцінити його за обʼєктивними сигналами (авторитет домену, ніша, давність в індексі) і порівняти кілька варіантів поруч.

    Аудиторія

    • Маркетологи та SEO-фахівці — шукають інструменти й майданчики в ніші, дивляться DR.
    • Засновники й продакт-менеджери — вивчають конкурентів і нові продукти у своїй категорії.
    • Розробники та ентузіасти — стежать за новинками й добирають інструменти.

    Структура

    Один HTML-файл, чотири екрани з маршрутами в адресі (#/catalog, #/new, #/compare, #/about). Стан фільтрів зберігається в адресі, тож будь-яку добірку можна надіслати посиланням. Список порівняння зберігається в браузері.

    Що варто знати про дані

    • Описи сайтів згенеровані мовною моделлю на боці FreeSerp і можуть бути неточними.
    • DR — оцінка авторитету домену від 0 до 100, а не якість продукту.
    • «Зʼявився в індексі» — дата, коли сайт уперше підтверджено живим, а не дата запуску.
    • API віддає щонайбільше 10 000 результатів на запит, тому глибокі сторінки недоступні — звужуйте фільтри.
    Дані: FreeSerp, публічний API без ключа. Тестовий проєкт.
